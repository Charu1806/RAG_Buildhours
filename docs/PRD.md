# PRD: HDFC Fund Facts FAQ (RAG Prototype)

**Product:** Facts-only RAG chatbot for five HDFC mutual funds listed on Groww  
**Type:** Working prototype / hobby project to test RAG  
**Source site:** [groww.in](https://groww.in/) · **AMC:** HDFC  
**Status:** Draft · **Date:** 30 Aug 2026

---

## 1. Problem

Investors looking at HDFC funds on Groww need quick, sourced answers to factual questions (expense ratio, SIP minimum, exit load, lock-in, riskometer, how to get a capital-gains statement). Today that means scanning long fund pages. There is no lightweight, citation-backed assistant that stays strictly on those pages and refuses advice.

## 2. Goal

Ship a **tiny Streamlit chatbot** that answers **factual questions only** from a **closed corpus of five Groww pages**, using a standard RAG pipeline (ingest → chunk → embed → retrieve → generate). Every answer must cite one source URL. The prototype exists to validate RAG quality, not to give investment advice.

**Success looks like:** a user can ask “What is the expense ratio of HDFC Large Cap?” and get a ≤3-sentence answer, one Groww citation, and a last-updated line — or a polite refusal if they ask “Should I buy this?”

---

## 3. Users & jobs

| Who | Job to be done |
|---|---|
| Curious investor (demo user) | Get a fact from one of the five funds without reading the full page |
| Builder / PM | Prove RAG works on a tiny, known corpus and catch edge cases |

No login. No personalization. No account data.

---

## 4. In scope

### 4.1 Corpus (hard lock)

Only these five public Groww pages. Nothing else — no other funds, no blogs, no app screenshots, no factsheet PDFs unless they are linked from these pages and we choose later to add them (v1: **pages only**).

| Category | Fund | URL |
|---|---|---|
| Large-cap | HDFC Large Cap Fund Direct Growth | https://groww.in/mutual-funds/hdfc-large-cap-fund-direct-growth |
| Flexi-cap | HDFC Flexi Cap Fund Direct Growth | https://groww.in/mutual-funds/hdfc-equity-fund-direct-growth |
| ELSS | HDFC ELSS Tax Saver Fund Direct Plan Growth | https://groww.in/mutual-funds/hdfc-elss-tax-saver-fund-direct-plan-growth |
| Small-cap | HDFC Small Cap Fund Direct Growth | https://groww.in/mutual-funds/hdfc-small-cap-fund-direct-growth |
| Hybrid | HDFC Balanced Advantage Fund Direct Growth | https://groww.in/mutual-funds/hdfc-balanced-advantage-fund-direct-growth |

### 4.2 Questions we answer

Factual lookups that appear on those pages, for example:

- Expense ratio
- Minimum SIP / lump sum
- Exit load
- ELSS lock-in
- Riskometer / benchmark
- How to download a capital-gains statement (if stated on-page)

### 4.3 Questions we refuse

Opinion, allocation, or “should I buy/sell/switch?”  
Performance computation or comparison (“which fund returned more?”, “what will 1L become?”).  
Anything needing data outside the five URLs.  
Any request that includes PII.

Refusal tone: polite, facts-only, plus one relevant educational / source link from the corpus when possible.

## 5. Functional requirements

| ID | Requirement | Priority |
|---|---|---|
| F1 | Chat UI: welcome line, 3 example questions, disclaimer **“Facts-only. No investment advice.”** | P0 |
| F2 | Answer factual queries from retrieved chunks only (no invented numbers) | P0 |
| F3 | Every answer includes **exactly one clear citation URL** (the Groww page used) | P0 |
| F4 | Answers ≤ **3 sentences** | P0 |
| F5 | Footer on every answer: **“Last updated from sources: &lt;date&gt;”** | P0 |
| F6 | Refuse advice / portfolio / buy-sell questions with a fixed polite message | P0 |
| F7 | Do not compute or compare returns; if asked, point user to official factsheet / on-page returns (link only) | P0 |
| F8 | Reject and do not store PAN, Aadhaar, account numbers, OTPs, emails, phone numbers | P0 |
| F9 | If retrieval is weak / no relevant chunk, say we don’t have that on the five pages — do not guess | P0 |
| F10 | Example questions on load (suggested chips): expense ratio, ELSS lock-in, min SIP | P1 |

---

## 6. Non-functional & policy constraints

- **Public sources only.** Corpus = the five Groww URLs.
- **No PII** in logs, prompts, or storage.
- **No performance claims** generated by the model.
- **Clarity:** short answers, always sourced, always dated.
- Prototype-grade: single local/demo user, no SLA, no auth.

---

## 7. UX (Streamlit)

- Groww-inspired palette (dark green / white / light grey; keep it simple).
- Single page: header + disclaimer + 3 clickable example questions + chat input + message history.
- Assistant bubble: answer text → citation link → last-updated line.
- No extra nav, no fund picker required (model should infer fund from the question; if ambiguous, ask which of the five).

---

## 8. Technical design (prototype stack)

```
5 Groww URLs
    → scrape / fetch page text
    → chunk
    → embed (sentence-transformers/all-MiniLM-L6-v2)
    → store (ChromaDB)
User question
    → PII + advice guardrails
    → embed query (same model)
    → retrieve top-k chunks
    → prompt (Mistral API) with chunks only
    → short answer + citation + last-updated
```

| Layer | Choice |
|---|---|
| Ingestion | Fetch the 5 URLs only; chunk by heading / fixed size with overlap |
| Embeddings | `sentence-transformers/all-MiniLM-L6-v2` (Hugging Face, free, lightweight) |
| Vector store | ChromaDB |
| LLM | Mistral (API key) |
| UI | Streamlit |

**Prompt rules:** use only provided chunks; if chunks don’t contain the fact, say so; never give buy/sell advice; never invent expense ratios or dates.

---

## 9. Out of scope (v1)

- Other AMCs, other HDFC funds, news, blogs
- Login, KYC, portfolio, order placement
- Return calculators, SIP calculators, comparisons
- Multi-turn “advisor” persona
- Production hosting, analytics, rate limits
- Storing user chat history beyond the session

---

## 10. Edge cases to test

| Case | Expected |
|---|---|
| “Expense ratio of HDFC Large Cap?” | Fact + that fund’s Groww URL + last-updated |
| “ELSS lock-in?” | 3-year lock-in (if on page) + ELSS page citation |
| “Minimum SIP?” | Number from the named fund, or ask which fund if unnamed |
| “Should I buy HDFC Small Cap?” | Refusal + no advice + optional educational link |
| “Which fund is better?” / “Compare 3Y returns” | Refuse to compute/compare; link to page/factsheet |
| “Expense ratio of SBI Bluechip?” | Out of corpus — we don’t have that |
| User pastes PAN / phone / email | Reject; do not echo or store |
| Empty / gibberish query | Ask for a factual question about one of the five funds |
| Question about something not on the pages | Honest “not in our sources” |
| Ambiguous “this fund” with no prior context | Ask user to name one of the five |

---

## 11. Acceptance criteria

1. Corpus ingest succeeds for all **5** URLs and those vectors are queryable in ChromaDB.  
2. At least the 3 UI example questions return a grounded, ≤3-sentence answer with **one** Groww citation and last-updated.  
3. Advice and comparison questions are refused 100% in a fixed test set (see §10).  
4. PII-looking input is blocked and never written to disk.  
5. UI shows welcome, 3 examples, and “Facts-only. No investment advice.” without extra chrome.

## 12. Open questions
